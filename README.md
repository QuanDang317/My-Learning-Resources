# My Learning Resources

Kho lưu trữ tài liệu học tập cá nhân trong quá trình học tập và phát triển kỹ năng Công nghệ thông tin.

## Nội dung

Repository bao gồm các tài liệu và tài nguyên liên quan đến:

* Machine Learning
* Deep Learning
* Data Science
* Algorithms & Data Structures
* Database / SQL
* Natural Language Processing (NLP)
* Lập trình và các tài liệu học tập khác
* Dataset và tài nguyên phục vụ thực hành

## Cấu trúc thư mục

```text
My-Learning-Resources/
│
├── AIO/
├── DATABASE/
├── DSA/
├── Machine Learning/
├── Deep Learning/
├── NLP/
├── Tài Liệu/
├── datasets/
└── README.md
```

*Cấu trúc thư mục có thể thay đổi theo quá trình bổ sung tài liệu.*

## Mục đích

Repository được sử dụng để:

* Lưu trữ và quản lý tài liệu học tập.
* Dễ dàng tìm kiếm và sử dụng lại tài liệu.
* Theo dõi quá trình học tập và tự học.
* Làm nguồn tham khảo cho các bài tập và dự án cá nhân.

## Topics đang học

**Programming:** Python, C/C++, Java, SQL

**AI/ML:** Machine Learning, Deep Learning, Computer Vision, NLP

**Computer Science:** Data Structures & Algorithms, Database

## Note

Đây là repository phục vụ mục đích học tập và tham khảo cá nhân.

Một số tài liệu có thể thuộc bản quyền của tác giả hoặc tổ chức phát hành. Repository không nhằm mục đích thương mại.
